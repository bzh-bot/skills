## Regenerating a voice-clone reference (only if you ask for a specific person's voice)

The default narration is `tts-qwen3.py --mode design` — synthesised from a
description, no reference audio. To clone a real voice instead:

```bash
scripts/make-reference-clip.sh --video recording.MOV --out /tmp/ref.wav --duration 10
# ranks 10 s windows by loudness if --start is omitted, loudnorm's to -18 LUFS,
# and writes ref.wav.txt (the whisper transcript that clone mode needs)
```

Copy large media local first — `~/gdrive` is an rclone mount that drops mid-read.
